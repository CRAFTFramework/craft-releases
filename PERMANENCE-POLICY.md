# Permanence Policy — craft-releases

CRAFT commits to **stable, permanent URLs** for everything published here, so any
human, AI, or script can rely on a link forever. These commitments mirror the
craft-recipe-library policy, generalized for releases.

1. **No file renames.** A published release path is never renamed.
2. **No deletions.** Published releases are never deleted (superseded, not removed).
3. **No org rename.** The `CRAFTFramework` org name is stable.
4. **No repo rename.** `craft-releases` keeps this name.
5. **No branch rename.** The default branch stays `main`.
6. **No silent redirects.** We do not introduce hidden GitHub redirects; changes
   are announced and dated.

Release-version paths and GitHub Release asset URLs are treated as **immutable**.
Any amendment to this policy is dated and announced before it takes effect.

_Policy v1.0 — governed by CD-042 Distribution Architecture._
