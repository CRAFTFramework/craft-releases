# CRAFT for Claude Cowork — stable channel

Downloads do **not** live in this folder. The signed, downloadable releases are on the
**GitHub Releases page**: https://github.com/CRAFTFramework/craft-releases/releases

This folder is just an optional index for the **stable** channel. A stable/GA release is tagged
`craft-for-claude-cowork-v1.NNNN.pYYYYMM.LLx` and is the single release flagged **Latest** — its
always-current download link never changes:

```
https://github.com/CRAFTFramework/craft-releases/releases/latest/download/craft-for-claude-cowork.zip
```
