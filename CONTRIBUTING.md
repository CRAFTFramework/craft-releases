# Contributing

This repository **distributes** CRAFT releases — it isn't where the framework source is
developed, so the most valuable contribution is **feedback**, not code.

## The best ways to help

- **Tell us how it went.** Tried a release? Open a Discussion (or an Issue) and say what worked,
  what confused you, and what you wish it did. Beginner feedback is especially welcome.
- **Report a problem.** If a download won't verify, a link is broken, or a release behaves
  unexpectedly, open an Issue using the bug template.
- **Ask questions.** No question is too basic. Use Discussions.

## Before you download

Verify any release with [VERIFY.md](VERIFY.md) — one `sha256sum -c` and one `gpg --verify`. If
verification fails, **do not use the download** and report it.

## What not to send here

Please don't open pull requests against this distribution repo — release contents are built and
signed upstream. If you want to suggest a framework change, describe it in a Discussion and we'll
route it.
